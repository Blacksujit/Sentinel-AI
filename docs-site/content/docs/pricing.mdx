# Pricing

SentinelAI's core is **open source and free**. The managed cloud adds the operational layer on top.

## Plans

| Plan | What you get | Best for |
|------|--------------|----------|
| **Free** | Self-hosted, open source, community support | Developers evaluating, small teams |
| **Pro** | Managed cloud, dashboard, alerting, settings history | AI/ML teams shipping LLM features in production |
| **Enterprise** | SLAs, SSO, audit logs, custom retention, compliance reports | Regulated companies, security review, procurement |

## The wedge

Engineers integrate the free SDK (`pip install sentinelai-risk`) in minutes. As usage grows into production, the managed cloud takes over dashboards, alerting, and team features.

## What's in the managed cloud

- **Dashboard** — real-time risk monitoring across your apps
- **Alerting** — get paged when hallucination rates spike
- **Settings history** — versioned detection policy
- **Audit logs** — every decision, attributable
- **Compliance reports** — EU AI Act, SOC 2, ISO 42001 evidence collection
