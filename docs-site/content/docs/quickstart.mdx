# Quick Start

Get SentinelAI running in under 60 seconds.

## 1. Install

```bash
pip install sentinelai-sdk
```

## 2. Verify a response

```python
from sentinelai import SentinelAIClient

client = SentinelAIClient(api_key="sk_...")

prompt = "What was Q3 revenue?"
llm_output = "Revenue grew 45% year over year."

result = client.verify(prompt=prompt, response=llm_output)

if result.status == "hallucinated":
    print(result.corrected)  # serve the fix, not the flaw
else:
    print(result.trust_score, result.reasons)
```

That's it. Every response is now scored, explained, and protected.

## 3. What you get back

The `result` object contains:

- **`status`** — `trusted`, `needs_review`, or `hallucinated`
- **`trust_score`** — a number from 0 (safe) to 100 (critical risk)
- **`reasons`** — human-readable, token-level explanations for every flag
- **`corrected`** — the cleaned response, present when auto-correction applies

<Callout type="info">
  Built-in retries, timeouts, and error handling are included. The SDK never
  leaves your request hanging.
</Callout>
